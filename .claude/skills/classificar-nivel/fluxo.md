FLUXO — classificar-nivel

1. Confirmar dimensão (perguntas.txt).
2. Reunir evidências disponíveis (diagnóstico existente + o que o
   usuário informou).
3. Aplicar os critérios de catalogo/niveis/<dimensao>.json do nível
   mais baixo para o mais alto, parar no último confirmado.
4. Determinar nível de confiança (confirmado/provável/parcial/incerto/
   sem dados). Se incerto/sem dados → marcar provisório.
5. Escrever a justificativa em linguagem simples (nunca só o código).
6. Salvar level-assessment e oferecer revisão humana.
