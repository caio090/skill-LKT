# Frameworks de funil

## Uso

Frameworks ajudam a pensar oferta, mensagem e sequência. Não devem virar uma arquitetura automática de campanhas.

## Topo, meio, fundo

Topo:
- descoberta;
- primeiro contato;
- atenção.

Meio:
- consideração;
- prova;
- comparação;
- desejo.

Fundo:
- ação;
- lead;
- conversa;
- compra.

Pós:
- follow-up;
- remarketing;
- retenção.

## Hook, Story, Offer

Como lente criativa:

**Hook**
- por que parar?
- qual tensão ou benefício aparece primeiro?

**Story**
- por que acreditar?
- contexto;
- demonstração;
- mecanismo;
- prova.

**Offer**
- o que fazer agora?
- qual oferta;
- qual condição;
- qual CTA.

Não reproduzir textos ou materiais protegidos de terceiros. Usar apenas o princípio operacional.

## Escada de valor

Planejar ofertas em níveis:

1. entrada;
2. oferta principal;
3. continuidade;
4. upsell/cross-sell.

O tráfego deve saber para qual degrau está enviando a pessoa.

## Lançamento

Estrutura conceitual:

1. preparação;
2. aquecimento;
3. captação;
4. conteúdo/prova;
5. abertura de oferta;
6. fechamento;
7. remarketing;
8. follow-up.

Não transformar cada fase em campanha separada automaticamente.

Com orçamento menor:
- condensar etapas;
- reutilizar audiência;
- priorizar a ação principal;
- usar remarketing somente quando houver volume.

## Frameworks de copy

### PAS
Problema → Agitação → Solução.

### AIDA
Atenção → Interesse → Desejo → Ação.

### BAB
Antes → Depois → Ponte.

### QUEST
Qualificar → Entender → Educar → Estimular → Transição.

### PPP
Imagem/possibilidade → Promessa → Prova → Empurrão para ação.

## Escolha do framework

Usar conforme:
- consciência do público;
- objetivo;
- criativo;
- prazo;
- oferta;
- estágio do funil.

Exemplo:
- topo: Hook + Story;
- meio: BAB, prova ou case;
- fundo: oferta + prova + CTA;
- remarketing: objeção específica + prova + CTA.

## Regra LKT

Nunca começar pelo framework.

Começar por:
negócio → objetivo → público → oferta → funil → orçamento → plataforma → campanha → criativo → tracking → comercial.

Framework entra para melhorar mensagem e sequência.
