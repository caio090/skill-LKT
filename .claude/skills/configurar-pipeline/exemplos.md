EXEMPLOS — configurar-pipeline

Exemplo 1 — Pipeline comercial:
  Lead → qualificado → diagnóstico → proposta enviada → negociação →
  fechado/perdido. Cada oportunidade tem responsável e próxima ação.

Exemplo 2 — Pipeline de recrutamento:
  Candidatura → triagem → entrevista → avaliação → aprovado/reprovado.

Contraexemplo (não é pipeline, é funil):
  "Quero saber a taxa de conversão de lead para cliente no mês" — isso
  é número agregado, é desenhar-funil, não configurar-pipeline.
