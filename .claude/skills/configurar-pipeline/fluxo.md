FLUXO — configurar-pipeline

1. Coletar respostas de perguntas.txt.
2. Definir etapas com critério de entrada e saída
   (schemas/etapa.schema.json).
3. Para cada item novo: etapa atual, data de entrada, responsável,
   próxima ação, prazo, prioridade — nunca criar item sem próxima ação.
4. Se houver automação permitida, encaminhar para automatizar-fluxo
   antes de ativar qualquer regra.
5. Gerar o documento final (ver saidas.md).
