FLUXO — criar-campanha

1. Coletar briefing (perguntas.txt).
2. Montar cronograma (produção → aprovação → ativação → encerramento).
3. Encaminhar para desenhar-funil se ainda não houver funil associado.
4. Encaminhar para estruturar-pagina-de-oferta se houver página nova.
5. Encaminhar para projecoes (tipo marketing) se precisar de
   investimento/alcance/leads projetados.
6. Declarar regra de atribuição (schemas/evento-conversao.schema.json)
   antes de considerar a campanha pronta para ativação.
7. Gerar o documento final e o checklist de aprovação (ver saidas.md).
