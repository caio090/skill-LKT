EXEMPLOS — criar-campanha

Exemplo 1 — Campanha de lançamento de produto digital:
  Anúncio → página de oferta → checkout → onboarding. Funil associado:
  visitante → cadastro → ativação → assinatura.

Exemplo 2 — Campanha de evento:
  Convite/anúncio → página de inscrição → confirmação → participação →
  follow-up pós-evento.

Contraexemplo (não é campanha, é processo):
  "Organiza como a gente atende todo cliente novo" — isso é operação
  contínua sem prazo definido, é mapear-processo, não criar-campanha.
