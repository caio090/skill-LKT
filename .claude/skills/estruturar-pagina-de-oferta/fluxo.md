FLUXO — estruturar-pagina-de-oferta

1. Coletar respostas de perguntas.txt.
2. Se houver expert pessoal, confirmar autorização de imagem antes de
   prosseguir — sem autorização confirmada, não usar foto/vídeo da
   pessoa.
3. Selecionar as seções pertinentes (nem toda página usa headline +
   prova + demonstração + expert + oferta + FAQ + CTA — só o que fizer
   sentido).
4. Registrar o evento de conversão associado
   (schemas/evento-conversao.schema.json).
5. Encaminhar para pagina-e-site → design-front-end →
   texto-natural-pt-br para a implementação.
