# Workflow — proposta

Sequência de referência para gerar escopo e preço. Executada pela skill
`proposta-e-precificacao`.

```
Escopo consolidado no planejamento
  → Composição do preço (estratégia + produção + tecnologia + operação
    + gestão + risco + margem + despesas externas − desconto aprovado)
  → Separação (implantação/recorrência/manutenção/avulso/custos externos)
  → Geração do documento no formato certo (MD/DOCX/PDF/PPTX)
  → Registro de condições de continuidade (nova fase vs. incluído)
  → Salvamento em .../04-comercial/ e atualização de PROJETO.md
```

Ver `.claude/skills/proposta-e-precificacao/SKILL.md`.
