# Workflow — planejamento

Sequência de referência depois do diagnóstico, antes de qualquer
produção ou proposta formal.

```
Diagnóstico consolidado
  → Definição de objetivos mensuráveis
  → Escopo (o que entra, o que não entra)
  → Entregáveis e responsáveis por papel
  → Dependências e custos externos
  → Roadmap (prioridade agora / fase futura)
  → Projeções, quando o projeto tiver componente financeiro/comercial
  → Encaminhamento para proposta (externo) ou execução direta (interno)
```

Usa `catalogo/modulos/diagnostico`, `.claude/skills/projecoes` e o
schema `schemas/projeto.schema.json` para registrar o plano no
`PROJETO.md`.
