# Workflow — pré-venda

Fase de identificação, coleta de informação, triagem e qualificação
anterior à venda — pode ser humana, automática ou híbrida.

```
Contato chega (formulário, quiz, WhatsApp, ligação, agente)
  → Coleta de informação mínima
  → Triagem/qualificação (só é qualificação se a resposta influencia
    avançar, priorizar, segmentar ou encaminhar — ver
    knowledge/projetos/ONTOLOGIA_PROCESSOS_FUNIS_PIPELINES.md)
  → Encaminhamento: descarta, aquece, ou vira oportunidade no pipeline
```
