# Workflow — pipelines

Sequência de referência para configurar e manter um pipeline.
Executada por `configurar-pipeline`.

```
Definir tipo de item e etapas
  → Definir critério de entrada/saída de cada etapa
  → Registrar cada item com responsável, próxima ação e prazo
  → Sinalizar item parado além do SLA
  → Encaminhar transição candidata a automação → automatizar-fluxo
```
