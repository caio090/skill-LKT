# Workflow — novo projeto

Sequência de referência ao abrir um workspace ou projeto novo. Executada
pela skill `novo-projeto`.

```
Entrada informal
  → Organização das informações
  → Classificação do projeto
  → Confirmação do workspace (novo ou existente)
  → Criação da estrutura pertinente ao tipo de projeto
  → Detecção de necessidade de processo/funil/pipeline/campanha
  → Encaminhamento para diagnóstico
```

Nunca pula direto para produção de conteúdo. Ver
`.claude/skills/novo-projeto/SKILL.md` para o passo a passo completo.
