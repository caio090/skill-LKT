# Workflow — campanhas

Sequência de referência de ponta a ponta para uma campanha. Executada
por `criar-campanha`.

```
Briefing (objetivo, público, oferta, canais, período, orçamento)
  → Funil associado (desenhar-funil, se ainda não existir)
  → Página de oferta (estruturar-pagina-de-oferta, se houver)
  → Projeção de investimento/alcance/leads (projecoes, quando fizer sentido)
  → Aprovação (checklist antes de ativar)
  → Ativação
  → Medição (analisar-conversao)
  → Relatório e aprendizados (encerramento)
```
