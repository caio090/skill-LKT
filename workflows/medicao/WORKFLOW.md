# Workflow — medição

Sequência de referência para acompanhar o resultado real de um projeto,
não só a entrega.

```
Entrega concluída
  → Definição/confirmação do indicador de sucesso (PROJETO.md)
  → Coleta do dado real (fonte registrada, nunca inventado)
  → Comparação com a projeção original, quando houver
    (schemas/projecao.schema.json)
  → Registro do resultado em .../08-medicao/
  → Atualização de métricas em catalogo/indicadores/ ou _memoria.json
```

Ver `.claude/skills/analisar-conversao` quando a medição envolver
funil/pipeline/campanha.
