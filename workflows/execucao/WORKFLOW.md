# Workflow — execução

Sequência de referência para a produção real das entregas, depois de
diagnóstico, planejamento e (quando externo) proposta aprovada.

```
Proposta aprovada / plano interno confirmado
  → Encaminhamento para o(s) módulo(s) certo(s) em catalogo/modulos/
  → Encadeamento de skills conforme o tipo de entrega (ver CLAUDE.md,
    seção "Fluxo de trabalho e skills")
  → Aplicação de texto-natural-pt-br em toda entrega voltada ao público
  → Atualização do estado do projeto para "em execução"
```

Nunca pula diagnóstico/planejamento para ir direto à produção, mesmo
quando o pedido original já menciona a entrega específica.
