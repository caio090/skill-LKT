# Workflow — diagnóstico

Sequência de referência para avaliar um workspace ou projeto. Executada
pela skill `diagnostico-empresarial`.

```
Seleção dos pilares pertinentes
  → Avaliação de cada pilar (o que existe, o que falta, evidência)
  → Mapeamento de como contatos/pessoas avançam (quando pertinente)
  → Classificação do modelo (processo/fluxo/funil/pipeline/campanha/jornada)
  → Consolidação (prioridade agora vs. depois)
  → Registro em .../01-diagnostico/ e atualização de PROJETO.md/_memoria.json
```

Nunca avalia os 16 pilares por padrão — só os pertinentes ao caso. Ver
`.claude/skills/diagnostico-empresarial/SKILL.md`.
