# Workflow — vendas (referência: venda consultiva)

```
Conteúdo ou indicação
  → Contato
  → Pré-venda (workflows/pre-venda/)
  → Diagnóstico
  → Proposta (proposta-e-precificacao)
  → Negociação (configurar-pipeline)
  → Contrato
  → Onboarding (workflows/onboarding/)
```

Para produto digital com checkout automático, ver o fluxo de campanha
em `workflows/campanhas/WORKFLOW.md` (anúncio → página/quiz →
qualificação → página de oferta → checkout → compra → onboarding).
