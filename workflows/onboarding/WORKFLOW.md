# Workflow — onboarding (pós-venda)

```
Contrato assinado / compra confirmada
  → Boas-vindas e coleta de dados de entrega
  → Estruturação do workspace/projeto (novo-projeto, se ainda não existir)
  → Entrega do primeiro valor (setup, primeira sessão, acesso ao produto)
  → Definição de indicador de sucesso do onboarding
  → Transição para "uso" (fora do escopo de onboarding)
```

Não confundir onboarding (início da relação) com implantação
(entrega do projeto) — ver `docs/METODO_DE_TRABALHO.md`, "implantação
não é continuidade".
