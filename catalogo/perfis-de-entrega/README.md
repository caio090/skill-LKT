# Catálogo de perfis de entrega

Pacotes estruturais ligados a um nível (`schemas/deliverable-profile.schema.json`)
— sem obrigar que todo cliente receba exatamente a mesma proposta. Ver
`knowledge/niveis/NIVEIS_E_PROPOSTAS.md`.

Cada perfil separa: obrigatório, recomendado, opcional, futuro, e não
incluso — usado pela skill `gerar-escopo-por-nivel` (escopo interno
completo) e `gerar-proposta-a-partir-do-nivel` (tradução comercial).

## Arquivo de exemplo

`perfil-maturidade-digital-estruturada.exemplo.json` — perfil de
entrega ligado ao nível "estruturada" do conjunto
`catalogo/niveis/maturidade-digital.exemplo.json`, marcado como
rascunho de referência (mesmo aviso de `catalogo/niveis/README.md`).

Nenhum perfil é obrigatório — cadastrar conforme os pacotes reais da
instalação forem se consolidando.
