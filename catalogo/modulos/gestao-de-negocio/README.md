# Gestão de negócio (Meu Negócio)

Módulo de gestão de negócio aplicada: consolida vendas, custos,
despesas, caixa, produtos, clientes, campanhas, estoque e decisões, e
aponta a próxima ação concreta. Skill principal: `gestao-de-negocio`.

Nome público (voltado ao dono do negócio): **Meu Negócio**. Termos
técnicos aparecem entre parênteses quando necessário — ex.: custo do
produto vendido (CMV), custo para conquistar cliente (CAC).

Arquitetura reutilizável para qualquer segmento; a especialização
`food-service/` cobre restaurante, hamburgueria, delivery, pizzaria,
lanchonete, confeitaria, cafeteria e bar. Ver
`docs/GLOSSARIO-GESTAO-DE-NEGOCIO.md` para os termos, e
`docs/auditorias/LOTE-0-AUDITORIA-SKILLS.md`/`docs/lotes/` para o
histórico de decisões.
