# Catálogo de indicadores

Definições reutilizáveis de como a instalação mede sucesso — nome do
indicador, fórmula, fonte de dado, frequência de medição. Não é onde
ficam os números reais de um workspace (isso vive em
`_memoria.json`/`.../08-medicao/` de cada workspace/projeto).

## Formato sugerido de um indicador (arquivo `.md` por indicador)

```markdown
# <Nome do indicador> (ex.: "CAC", "Taxa de conversão de proposta")

## O que mede
## Fórmula
## Fonte de dado
## Frequência de medição
## Quando usar
## Cuidado ao interpretar
(ex.: nunca confundir receita com faturamento, margem com lucro)
```

Ver `docs/GLOSSARIO-GESTAO-DE-NEGOCIO.md` para as definições já
consolidadas de receita, faturamento, lucro, margem, CAC, LTV, ROI,
ROAS, ticket médio e conversão.
