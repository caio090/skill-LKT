# Catálogo de serviços

Definições reutilizáveis do que a instalação sabe entregar — não é onde
fica o dado real de um cliente (isso vive em `workspaces/`).

Um serviço registrado aqui serve de ponto de partida para
`proposta-e-precificacao`: nome, descrição, entregáveis padrão,
dependências típicas, faixa de preço de referência (não um preço fixo —
a composição real é sempre calculada por projeto).

## Formato sugerido de um serviço (arquivo `.md` por serviço)

```markdown
# <Nome do serviço>

## O que é
## Para quem serve
## Entregáveis padrão
## Dependências típicas
## Faixa de preço de referência
(composição típica — implantação, recorrência, custo externo — nunca
preço fechado sem calcular o projeto real)
## Continuidade
(o que é implantação vs. o que exige novo contrato)
```

Nenhum serviço cadastrado ainda — cadastre conforme a instalação
consolidar o que oferece de forma recorrente.
