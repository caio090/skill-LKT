# Catálogo de entregáveis

Definições reutilizáveis de tipos de entrega (o formato, o padrão de
qualidade esperado, onde salvar) — não é onde ficam as entregas reais de
um workspace (isso vive em `workspaces/<tipo>/<slug>/.../07-entregaveis/`).

## Formato sugerido de um entregável (arquivo `.md` por tipo)

```markdown
# <Nome do tipo de entregável> (ex.: "Landing page", "Relatório mensal")

## Formato de saída
(ver docs/PADRAO_DE_ARQUIVOS.md — TXT/MD/JSON/CSV/DOCX/PPTX/PDF)
## Critérios de qualidade mínimos
## Skill(s) responsável(is)
## Onde salvar
```
