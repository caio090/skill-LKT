# Conhecimento — operacao

Esta pasta guarda ontologias e definições conceituais de operacao que
atravessam mais de um projeto ou workspace (o "o que significa e quando
usar"). Cobre: processos, capacidade, responsáveis por papel, fornecedores, produção, entrega, qualidade, gargalos.

Para "como fazer" operacionalmente nesta área, ver
`catalogo/modulos/operacional/`. Para a ontologia central de
processo/funil/pipeline/campanha (usada por todas as áreas), ver
`knowledge/projetos/ONTOLOGIA_PROCESSOS_FUNIS_PIPELINES.md`.

Nenhuma ontologia específica de operacao registrada além do que já está
em `knowledge/projetos/` e `knowledge/marketing/` — adicionar aqui
somente quando um conceito específico desta área precisar de definição
próxima (não duplicar o que já está coberto pela ontologia central).
