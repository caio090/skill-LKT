# Templates de cliente

Modelo de `CLIENTE.md` usado pela skill `novo-projeto` ao criar um
cliente novo. Ver o template embutido na própria skill
(`.claude/skills/novo-projeto/SKILL.md`, Passo 3) — este diretório existe
para variações por tipo de negócio quando fizerem falta (ex.: cliente com
múltiplas unidades/franquias), evitando duplicar o modelo-base dentro de
cada skill que precisar dele.
