# Templates de documentos

Modelos usados por `criar-documento`, `criar-apresentacao` e `criar-pdf`.

- `proposta-comercial.md` — estrutura-base de proposta pra cliente.
- `relatorio.md` — estrutura-base de relatório (diagnóstico, resultado de
  campanha, financeiro, etc.).

Populado incrementalmente conforme cada lote precisar de um modelo novo
— não criar modelo pra tipo de documento que nenhuma skill usa ainda.
