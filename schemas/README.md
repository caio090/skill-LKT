# Schemas

Formatos de dados esperados para validação — JSON Schema ou estrutura
Markdown documentada, usados pelas skills que leem/gravam dados
estruturados (financeiro, planilhas, briefings).

Schemas de configuração interna do próprio sistema (não de domínio de
negócio) ficam em `.lkt-system/schemas/`, não aqui.

Populado a partir do Lote 4 (financeiro) em diante, conforme cada domínio
precisar de um formato validável. Não criar schema para dado que nenhuma
skill ainda consome.
