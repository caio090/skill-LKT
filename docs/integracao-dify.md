# Integracao Dify

Fonte: https://github.com/langgenius/dify

Dify e uma plataforma completa, nao uma skill Claude Code. Para instala-la, clone sua origem em uma pasta propria, consulte a documentacao oficial e a LICENSE (Apache 2.0 modificada, com restricoes de uso multi-tenant e de marca no frontend).

O LKT pode registrar essa fonte e orientar a instalacao, sem confundir a plataforma com skills. Nao copie segredos nem dados de clientes ao repositorio publico.
