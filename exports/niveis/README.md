# Exports de níveis (contrato de dados entre camadas)

Ver `docs/CONTRATO_DE_DADOS_DOS_NIVEIS.md`. Um export por
avaliação/recomendação, gerado pela skill `recomendar-nivel`, em
`exports/niveis/{workspace}/{projeto}/level-recommendation.json`.

`EXEMPLO/EXEMPLO/` é um exemplo de referência — não é dado real. Nenhum
script deste repositório faz chamada de rede para exportar ou importar
esses arquivos; o contrato é só o formato de arquivo.
